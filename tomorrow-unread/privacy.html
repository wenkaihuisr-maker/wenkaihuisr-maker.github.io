隐私政策

生效日期：2026年9月14日 · 开发者 kaihui wen

游戏内数据

《明日未读》无需账号。游戏人物、来信与档案均为虚构；应用不读取真实聊天、联系人、照片或位置。没有广告、分析 SDK 或开发者运营的服务器，也不会将游戏进度传送给开发者。

本地进度与备份

应用在自己的设备存储空间保存调查阶段、已收集线索、选择记录及结局，使用应用偏好记录是否进入过游戏，以及你选择的语言或跟随系统的设置。这些偏好只保存在本机，不会传送给开发者。重新开始前会保留旧存档备份，以免误覆盖。应用数据可能随你启用的 Apple 设备备份功能被备份；这由系统和你的设置控制。

主动分享

只有你主动打开分享菜单并选择目标时，系统才会把结案图片交给你指定的应用或保存位置。默认卡片不显示剧情结局，可主动选择显示；接收方对内容的处理遵循其自身政策。应用不读取你的相册。

删除数据

在 iOS 设置的 iPhone 储存空间中选择本应用并选择“删除 App”（不是“卸载 App”），可删除本机应用数据、偏好及旧存档备份。已分享或保存到其他位置的图片需在相应位置另行删除。Apple 系统备份中的副本由你的备份设置管理。开发者没有服务器上的进度副本。

支持与网站

本网站托管于 GitHub Pages，托管服务可能处理访问所需的 IP 等请求信息，适用 GitHub 隐私声明。本站不添加广告、分析脚本或表单。你主动提交公开支持请求时，内容会在 GitHub 公开，请勿提交私人信息或存档。

联系与更新

疑问可通过 开发者的公开支持渠道联系，并注明“明日未读”。政策更新会在本页列明新的生效日期。
