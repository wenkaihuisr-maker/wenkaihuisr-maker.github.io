隱私權政策

生效日期：2026年9月14日 · 開發者 kaihui wen

遊戲內資料

《明日未讀》無須帳號。遊戲人物、來信與檔案均為虛構；應用程式不讀取真實聊天、聯絡人、照片或位置。沒有廣告、分析 SDK 或開發者營運的伺服器，也不會將遊戲進度傳送給開發者。

本地進度、偏好設定與備份

應用程式在裝置內自己的儲存空間保存調查階段、已收集線索、選擇紀錄與結局，並使用應用程式偏好設定記錄是否已進入遊戲，以及你選擇的語言或跟隨系統的設定。這些偏好只儲存在本機，不會傳送給開發者。重新開始前會保留舊存檔備份，以免誤覆寫。應用程式資料可能隨你啟用的 Apple 裝置備份功能一併備份；這由系統與你的設定控制。

主動分享

只有你主動開啟分享選單並選擇對象時，系統才會把結案圖片交給你指定的應用程式或儲存位置。預設卡片不顯示劇情結局，可主動選擇顯示；接收方對內容的處理依其自身政策辦理。應用程式不讀取你的相簿。

刪除資料

在 iOS 設定的 iPhone 儲存空間中選擇本應用程式，再選「刪除 App」（不是「卸載 App」），可刪除本機應用程式資料、偏好設定及舊存檔備份。已分享或儲存至其他位置的圖片，需要在對應位置另行刪除。Apple 系統備份中的副本由你的備份設定管理。開發者沒有伺服器上的進度副本。

支援與網站

本網站託管於 GitHub Pages，託管服務可能處理存取所需的 IP 等請求資訊，適用 GitHub 隱私聲明。本站不加入廣告、分析指令碼或表單。你主動提交公開支援請求時，內容會在 GitHub 公開，請勿提交私人資訊或存檔。

聯絡與更新

如有疑問，可透過開發者的公開支援管道聯絡，並註明「明日未讀」。政策更新時會在本頁列出新的生效日期。
