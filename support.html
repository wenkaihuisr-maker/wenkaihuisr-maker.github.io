Support

Effective date: September 1, 2026

Start
Create a project, choose a template, resolve Coverage Check findings, then start shooting from the plan.
Permissions
Camera and Microphone are requested only for recording. Photos and Files remain available as explicit import alternatives.
Restore Purchases
Open Settings and choose Restore Purchases while using the same Apple Account that made the Creator Lifetime purchase.
Project backup and restore
Creator can export a `.wrapsureproject` backup and restore it from Settings. Keep the package intact; restore validates its manifest and media before publication.
Export troubleshooting
Choose project backup, PDF, CSV, Photos, or Files. If Photos permission is denied, choose Files where offered. If device storage is low, free space before retrying. After an export succeeds, use the system share sheet to share the produced file; WrapSure does not upload it.
Data deletion
Delete a project in WrapSure to remove its app-owned project content. Remove exported copies separately from the Files, Photos, or other destination where you saved or shared them. WrapSure has no account or backend copy to delete.
Version
Version 1.0 · Build 1
Contact
Open a public support request. Describe the App version, device model, iOS version, steps, expected result, and actual result. Do not attach private recordings or sensitive data.

支持

生效日期：2026 年 9 月 1 日

开始
创建项目、选择模板、处理覆盖检查，再从规划中开始拍摄。
权限
仅在录制时请求相机与麦克风；照片和文件可作为主动导入备选。
恢复购买
在“设置”中选择“恢复购买”，并使用曾购买 Creator Lifetime 的同一 Apple 账号。
项目备份与恢复
Creator 可导出 `.wrapsureproject` 备份，并从“设置”恢复。请保持文件包完整；发布前会验证清单与媒体。
导出故障排查
可选择项目备份、PDF、CSV、照片或文件。照片权限被拒绝时，可在支持的流程中选择文件。设备存储空间不足时，请先释放空间再重试。导出成功后，可用系统分享面板分享生成的文件；WrapSure 不会上传。
数据删除
在 WrapSure 中删除项目可移除应用拥有的项目内容。已导出的副本需在你保存或分享到的“文件”、“照片”或其他位置另行删除。WrapSure 没有可删除的账户或后端副本。
版本
Version 1.0 · Build 1
联系
